## 一、一句话定位

Agent Chat 是一个**多角色 AI 社交客户端**：用户导入角色卡后，可以和多个 AI 角色私聊、群聊，角色有自己的记忆、朋友圈和主页。

- 和 SillyTavern 比：不是单人角色扮演，而是多角色有自己的社交关系与时间线。
- 和 Character.AI 比：角色卡本地导入，数据自己掌握。

---

### 7.1 七类冒烟（具体操作）

前提：本机前后端已起（常见 `8787` / `5173`），至少导入 1 个角色卡；私聊会话已存在。群聊冒烟需 ≥2 角色建群。

| # | 类 | UI 步骤（优先） | 等价 API / 观察点 | 通过标准 |
| - | -- | -------------- | ----------------- | -------- |
| 1 | **私聊** | 左栏「消息」→ 点开某私聊 → 输入框发一句短文 → 等回复 | `POST /api/conversations/:id/messages` | 用户泡 + 角色泡均出现；无 5xx |
| 2 | **群聊** | 「通讯录」→ 建群或打开已有群 → 发一句；可选点 @ 某成员 | 同上，body 带 `mention_character_id`（若 UI 有 @） | 至少一名角色回复；无 5xx |
| 3 | **记忆** | 私聊中说一句可记事实（如「我叫小明，住在上海」）→ 多聊两轮 → 打开该角色主页看「记忆」列表；或看聊天中耳语/待审提示 | 角色主页 `listMemories`；冲突时按提示确认/否认；`GET /api/characters/:id/memory-notices` | 出现新笔记，或耳语/待审可见；门控默认 off 时不强求 Laya |
| 4 | **朋友圈** | 左栏「空间」→「发动态」写字发布 → 等角色赞/评（主动总开关开着）；对角色动态写一条评论 → 等作者回评（M-01） | `POST /api/moments`；`POST /api/moments/:id/like|comments`；通讯录「让 TA 发动态」→ `POST /api/moments/generate` | 用户帖上墙；可见角色赞或评；作者回评至少一条（或结算日志显示已调度） |
| 5 | **读图** | 私聊输入区点「发送图片」→ 选一张本地图（≤5MB）→ 等角色读图回复 | `POST /api/conversations/:id/messages/image` | 图泡上墙；角色文字回复提到图意；Key 失败则有明确失败文案（代码在、未实打可不挡关，须记一笔） |
| 6 | **生图** | 私聊发「画一张橘猫」类短句 → 等生图泡 | 文本消息路径触发 `wantsImageGeneration` → Kolors | 出现带 `image_path` 的助手泡，或明确 Key/模型失败文案 |
| 7 | **语音** | 私聊按住「按住说话」→ 松开发送 → 看转写与回复；点助手语音泡/TTS（若有） | `POST /api/conversations/:id/messages/voice`；`GET /api/messages/:id/tts` | 语音消息上墙且有转写；角色回复；可选 TTS 可播 |

冒烟记录建议写在问题表使用说明或本阶段收口备注：日期、机器、通过/失败原因。
