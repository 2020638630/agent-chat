## 续债清单（可执行）

### X05-D1 冲突确认无按钮（P1）

- **可复现**：私聊改称呼/饮品 → 出现「改，还是仍用…？」→ 用户回「嗯」「随便」等非 accept/reject 句 → pending 一直挂着；下一轮仍可能被问或静默。
- **建议**：确认气泡加「改 / 不改」快捷（或 `source=memory_confirm` 专用 chips）；自然语言解析保留作兜底。
- **阶段**：体验债 / 可挂 UI 或记忆小刀，不并 N-02。

### X05-D2 pending 无 TTL（P2）

- **可复现**：确认后长时间不答 → `status=pending` 永久；后续同型冲突只更新 pending 内容。
- **建议**：TTL（如 7 天）自动 `superseded`，或资料页「待确认记忆」可丢弃。
- **阶段**：二期池。

### X05-D3 确认气泡异步晚到（P2）

- **可复现**：用户说「以后叫我X」→ 本轮 LLM 仍按旧称呼答完 → extract 异步后才插入 `memory_confirm`。
- **建议**：冲突在写路径能同步拦截时提前问；或确认到达后短系统提示。大改，只记账。
- **阶段**：二期池。

### X05-D4 过召回仍纯提示词（P2，R-06 已知残）

- **可复现**：偶发忽略 honor/sticky，清单式「唤君××。饮温水。」仍可能出现（R-06 备忘：无后处理校验）。
- **建议**：轻量后处理（近窗过召回句式检测 → 重写或删清单句）；或评测集回归。不做大模型路由。
- **阶段**：二期池；与 D-05 可观测可并列。

### X05-D5 提取失败用户无感（P2，D-05 延伸）

- **可复现**：extract `fail_llm` / `empty` 仅 `[memory.obs]`；耳语只在真正写入 notice 后出现。
- **建议**：debug 开关下轻量「这次没记下」；正式环境先指标。
- **阶段**：挂 D-05 续；不单开大功能。

### X05-D6 MEMORY_GATE 默认 off（P3，=D-24）

- **现象**：`MEMORY_GATE_BACKEND=off`；Laya 本机不可用；heuristic 仅 fixtures。
- **建议**：维持 off；门控生产化单独立项。
- **阶段**：已有 D-24，不重复开工。
