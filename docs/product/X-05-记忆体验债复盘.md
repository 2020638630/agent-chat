## 续债清单（可执行）

### X05-D1 冲突确认快捷按钮（P1）— **已关闭（2026-10-13 BF，本次新做）**

- **可复现（原）**：私聊改称呼/饮品 → 出现「改，还是仍用…？」→ 用户回「嗯」「随便」等非 accept/reject 句 → pending 一直挂着。
- **落地**：`source=memory_confirm` 气泡下挂「改 / 不改」chips；点击走既有 `sendQuickText` → `resolvePendingMemoryConfirm`（自然语言解析仍作兜底）。仅对线程末尾尚未被用户回复的确认气泡显示。私聊发送后短轮询 `listMessages` 以便异步确认气泡入屏。
- **选择**：最小解释——不新开 API、不改服务端解析；chip 文案固定「改」「不改」，与 R-05 accept/reject 提示词对齐。
- **口径**：先前问题表仅有 X05-D1 行、**无对应功能 commit**（误传 SHA `a151f0b` 不存在）；本轮 BF **新做**落地（`b851189`），属正确补做而非重复关闭。
- **非本刀**：X05-D2～D5、过召回提示词、N-02、D-02b 抽取。
